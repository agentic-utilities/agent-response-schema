# Contributing to agent-response-schema

First off, thank you for considering contributing to `@agentic-utilities/agent-response-schema`! 

## Local Development Setup

1. **Fork and clone** the repository.
2. **Install dependencies**: Run `npm install` in the root directory.
3. **Run tests**: Make sure all tests pass by running `npm run test`. We use Vitest for lightning-fast testing!

## Making Changes

- Create a new branch for your feature or bugfix (e.g., `feat/add-new-coercion` or `fix/repair-bug`).
- Write tests for your changes. If you are adding a new repair strategy, add a test case in the `tests/` folder.
- Run `npm run build` and `npm run test` to ensure everything compiles and passes perfectly.

## Submitting a Pull Request

- Push your branch to your fork.
- Open a Pull Request against the `main` branch.
- Provide a clear description of the problem you're solving and the approach you took.
